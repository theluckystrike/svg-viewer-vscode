# Settings

| Setting | Default | What it does |
|---|---|---|
| `svgViewer.preview.autoOpen` | false | Open the preview beside the editor when you open an .svg file as text. |
| `svgViewer.defaultBackground` | checker | Background until you pick one in the toolbar. The toolbar choice is kept per workspace. |
| `svgViewer.mouseWheel` | zoom | zoom: the wheel zooms at the pointer. scroll: the wheel pans and Ctrl or Cmd + wheel zooms. |
| `svgViewer.maxFileMB` | 50 | Larger files show their size first and draw when you click Render it. |
| `svgViewer.askForRating` | true | Ask at most two times for a Marketplace rating. |
| `svgViewer.showSupportLinks` | true | Show the Sponsor and More free viewers links in the status line. |
