# Zoom, pan and the viewBox

| Action | Mouse or key |
|---|---|
| Zoom at the pointer | Scroll the wheel, or pinch on a trackpad |
| Pan | Drag with the left or middle button, at any zoom. Shift + wheel pans too. |
| Fit the picture | Fit, or 0 |
| Actual size | 1:1, or 1 |
| Zoom in and out | + and - |
| viewBox outline | viewBox, or V |

The view stays where you left it when the file changes and after a window reload.

With viewBox on, a dashed line marks the viewBox and the rest is dimmed. The picture is drawn with a margin
around it, so shapes that sit outside the viewBox show up in the dim area.
